    📘 Tool Kaise Use Karein (Hindi Guide)

    1
    Channel Details bharo: Apna niche, subscribers, average views per video, monthly upload count aur engagement rate daalo. Agar exact number nahi pata to andaza (estimate) bhi chalega.
    2
    Audience Country Mix: YouTube Studio → Audience tab me dekho ki tumhare viewers kaunse country se aate hain. India, Tier-1 (US/UK/Canada/Australia) aur baaki countries ka % daalo — total 100% hona chahiye.
    3
    Monetization Streams select karo: Jo bhi income source abhi active hai ya plan kar rahe ho (AdSense, Sponsorship, Affiliate, etc.) unpar click karo.
    4
    "Generate Revenue Strategy" dabao: Turant tumhe monthly revenue estimate, diversification score, sponsorship rate aur growth strategy mil jayegi.
    5
    Sponsorship Rate Calculator se pata karo brands ko kitna charge karna chahiye — yeh number negotiation me kaam aayega.
    6
    90-Day Action Plan follow karo — checkboxes tick karte jao, progress apne aap save hoti hai (browser me).
    7
    Save Profile dabao taaki agli baar aake wahi data wapas load kar sako. Export Report se pura analysis text file me download kar sakte ho — client ko dikhane ke liye bhi use kar sakte ho.
    8
    Optional AI Strategy: Agar tumhare paas Claude API key hai to "Get Deeper AI Strategy" se aur detailed, personalized growth plan generate kar sakte ho. Key na ho to bhi tool poori tarah kaam karega (rule-based strategy).
